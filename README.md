# COMMDIS1B

SLP 1B Study Repository — Comm Dis 1B

## Setup

1. Open https://thetripleb.github.io/COMMDIS1B/ in your browser
2. Go to **Manage Data > GitHub Sync**
3. Enter your GitHub PAT (Contents: read/write on this repo)
4. Click **Save & Connect**

Data is stored in `commdis1b_data.json` and syncs automatically across devices.
